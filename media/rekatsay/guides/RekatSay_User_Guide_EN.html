RekatSay — User Guide

MSK Labs • Mobile (Android / iOS) • Language: EN

Version: v1.3.2 Date: 27.11.2026
RekatSay helps you track sajdah and rakah counts during prayer using your device's ambient light sensor.

1. Quick Start (Main Session)

  • Phone Placement: Place your phone flat in front of or beside your prayer mat with the screen facing up so your head/body casts a shadow over the sensor during sajdah.
  • Starting: Tap Start to begin counting. Each approach and return cycle counts as 1 Sajdah; every 2 Sajdahs count as 1 Rakah.
  • Pausing & Resetting: Finish pauses the session, Restart resumes from where you left off, and Reset clears the counters.
  • Dark / Light Mode: Toggle using the top-right switch. To exit Dark mode, tap the switch or double-tap the screen.
  • Info Icon: The top-right i icon shows a quick reminder about Dark mode usage.

2. General Display Settings

  • App Language: Switch instantly between TR / EN / AR from the top bar in Settings.
  • Rakah Display Mode: Choose whether the counter displays the Current Rakah or Finished Rakah.
  • Font Size & Colors: Adjust Rakah and Sajdah counter sizes and customize Background, Header, Counter, Start, and Reset button colors.
  • Brightness Note: The app does not change your device's system screen brightness.
  • Reset to Defaults: Restores all colors, font sizes, and display preferences to their initial state.

3. Calibration & Live Sensor Diagnostics

  • Live Sensor Diagnostics: Monitor Ambient Baseline (lx), Live Light (lx), Live Ratio (%), and Lowest Ratio (%) in real time.
  • Live Trial: Tap Start Live Trial and perform a test sajdah to verify that the light ratio drops noticeably.
  • Reset Calibration: Tap Reset Calibration to measure a new baseline if room lighting or phone position changes.
  • Analysis Results: View Min lx, Max lx, %Drop, and %Recovery for recent records and copy them to your clipboard. Data is recorded anonymously only during successful sessions.

4. Advanced Settings (Measurement Sensitivity)

  • Using the default values is recommended if you are unsure about technical settings.
  • Sajdah Threshold (Default 11.0%): Lower slightly if small unrelated movements are counted; raise slightly if real sajdahs are missed.
  • Invalid Move Threshold (Default 19.0%): Movements remaining above this threshold are treated as invalid (e.g., leaning or support).
  • Both thresholds can be adjusted in ±0.5 steps or restored with the Default button.

5. FAQ & Tips

  • "Suitable sensor data not found" warning: Your device's ambient light sensor may be limited or blocked by a case/screen protector. Try a different angle.
  • Light source placement: Avoid placing the phone directly under a lamp where no shadow falls; position it so your shadow covers the sensor during sajdah.
  • Dark Mode: Dims the screen in low-light environments so the display does not distract you.
